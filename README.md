# 🎓  Игровая академия программирования
**Репозиторий учебных веб-проектов для студентов и энтузиастов IT**

**TutorialApp** — это коллекция веб-приложений, созданных в игровой форме для обучения студентов и детей основам программирования и смежным информационным дисциплинам. Цель проекта — сделать изучение IT-направлений наглядным, увлекательным и интерактивным.

**TutorialApp** — это живая коллекция интерактивных проектов, где сложные концепции программирования и информатики объясняются через игру и визуализацию. Здесь вы не найдете скучной теории — только код, викторины, симуляции и рабочие примеры от базового HTML до FastAPI и намеков на Docker.
