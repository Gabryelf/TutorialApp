# 🐲 Math Monster — Математическая битва с коллекцией знаний

**Math Monster** — это обучающая HTML5-игра для детей, в которой игрок решает примеры на сложение и вычитание, зарабатывает очки, открывает математические факты и бьёт личные рекорды. Игра адаптирована под ПК и мобильные устройства (портретная и альбомная ориентации), поддерживает Яндекс SDK (реклама, лидерборды) и полностью работает офлайн.

### Игровая механика (пошагово)

1. **Генерация примера**  
   Функция `generateMathQuestion()` создаёт случайный пример:
   - 50% вероятность сложения, 50% — вычитания
   - Числа от 1 до 20 (результат не более 20)
   - Формирует 4 варианта ответа (1 правильный + 3 случайных в диапазоне ±2)

2. **Проверка ответа**  
   - Правильно → +1 очко, монстрик радуется, задержка 700 мс
   - Неправильно → −1 жизнь, показ правильного ответа, задержка 1000 мс

3. **Система жизней**  
   - Старт: 3 жизни (отображаются сердечками ❤️)
   - При 0 жизней → `gameOver()`, блокировка кнопок, показ кнопки «Новая игра»

4. **Коллекция фактов**  
   - Массив `ALL_FACTS` (30 элементов)
   - Каждые 10 очков → открывается новый факт (по порядку)
   - Открытые факты сохраняются в `localStorage`

5. **Рекорды**  
   - `bestScore` хранится в `localStorage`
   - Обновляется при превышении текущего рекорда

## 🚀 Установка и запуск

### Локальный запуск (без интернета)

```bash
# 1. Клонируй репозиторий или скачай архив
git clone https://github.com/your-username/math-monster.git

# 2. Перейди в папку проекта
cd math-monster

# 3. Открой index.html в любом браузере
# (просто дважды кликни по файлу)
```

### Запуск с эмуляцией мобильного устройства

1. Открой **Chrome DevTools** (F12)
2. Нажми на иконку телефона (Ctrl+Shift+M)
3. Выбери устройство: iPhone 12, Pixel 5 и т.д.
4. Проверь портретную и альбомную ориентации

### Проверка работы Яндекс SDK (опционально)

SDK подключается асинхронно и не блокирует игру. Для теста с SDK:

```bash
# Запусти локальный сервер (чтобы избежать CORS)
npx http-server . -p 8080

# Открой в браузере
http://localhost:8080
```

## 📦 Публикация на Яндекс.Играх

### Подготовка файлов

1. **Переименуй папку и архив** (только латиница, без пробелов):
   ```
   ❌ "Моя игра" → ✅ "math-monster"
   ❌ "game v1.zip" → ✅ "game_v1.zip"
   ```

2. **Создай ZIP-архив** со следующей структурой:
   ```
   math-monster.zip
   └── index.html          # главный файл (обязательно)
   └── icon.png            # иконка 512×512 (рекомендуется)
   ```

3. **Подготовь медиафайлы**:
   - Иконка: `icon.png`, 512×512 px
   - Скриншоты: 3–5 штук, 1280×720 px, названия `screenshot1.png`, `screenshot2.png`...
   - Видео (опционально): `gameplay.mp4`, 30–60 секунд

### Пошаговая инструкция

| Шаг | Действие |
|-----|----------|
| 1 | Перейди на [Яндекс.Игры для разработчиков](https://yandex.ru/games/dev) |
| 2 | Авторизуйся под Яндекс ID |
| 3 | Нажми **«Создать игру»** |
| 4 | Заполни все поля (см. таблицу ниже) |
| 5 | Загрузи иконку, скриншоты, видео |
| 6 | В разделе «Файлы игры» загрузи `math-monster.zip` |
| 7 | Нажми **«Отправить на модерацию»** |

### Поля для заполнения (пример)

| Поле | Пример заполнения |
|------|-------------------|
| **Название** | Математический монстрик |

## 🔌 API и интеграции

### Яндекс SDK (v2)

SDK подключается асинхронно и не ломает игру при отсутствии интернета.

```javascript
// Подключение
<script src="https://yandex.ru/games/sdk/v2"></script>

// Инициализация
window.YaGames.init().then(sdk => {
    // Показ рекламы при проигрыше
    sdk.adv.showFullscreen();
    
    // Отправка рекорда в лидерборд
    sdk.leaderboard.setScore('math_monster_leaderboard', currentScore);
});
```

**Текущая интеграция:**
- ✅ SDK загружается
- ✅ При `gameOver()` вызывается реклама (если SDK готов)
- ⚠️ Лидерборд не реализован (можно добавить)

### localStorage API

| Ключ | Тип | Что хранит |
|------|-----|------------|
| `mathMonsterBest` | number | Лучший счёт игрока |
| `mathFactsUnlocked` | boolean[] | Массив открытых фактов (30 элементов) |

**Пример чтения:**
```javascript
let best = localStorage.getItem('mathMonsterBest') || 0;
let facts = JSON.parse(localStorage.getItem('mathFactsUnlocked'));
```

- [ ] **Анимация нажатия на кнопки** (уже есть `:active`, можно усилить)

### Средней сложности

- [ ] **Новые темы** (не только математика)  
  - География: «Столица Франции?»  
  - Английский: «Cat — это...»

## 🐞 Известные проблемы

| Проблема | Причина | Временное решение |
|----------|---------|-------------------|
| На некоторых телефонах кнопки «Коллекция» не открывается | z-index конфликт | Обновить страницу |
| При медленном интернете SDK не инициализируется | Асинхронная загрузка | Игра работает без SDK |
| Локально не работает реклама | Требуется HTTPS | При публикации на Яндекс.Играх заработает |
| Факты сбрасываются при очистке кэша | localStorage очищается | Предупредить игроков |
